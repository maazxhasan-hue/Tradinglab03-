## Hourly work discovery
GitHub Actions is configured to run the opportunity scout hourly and save a downloadable report artifact. The enabled public feeds are Reddit r/forhire and Codeur's public project feed; Codeur listings are mainly French-language and platform access/fees must be checked before applying. Freelancer.com sources are disabled by owner decision and its SDK/token setup has been removed from the scout workflow. Other feeds remain disabled where previous runner checks returned rate limits, access challenges, or missing endpoints. Public listings are unverified leads, not guaranteed paid contracts. The scout does not auto-apply, bid, or message clients. See [Opportunity Source Policy](company/OPPORTUNITY_SOURCE_POLICY.md) before enabling another source. Scheduled runs must be verified in Actions; configuration alone is not proof that every run succeeded.

## Additional revenue agent
Business Intelligence & Revenue Scout can analyze a single public HTTPS homepage for visible SEO, mobile, heading, image-accessibility, and contact-path signals, map observed signals to services, and draft a proposal/conversation. It does not send it. Payment verification, invoicing/payment processor integration, connected LLM agents, and telephony remain future integrations.

## Production client intake

The website includes an explicit consent checkbox and a production submission path. The intake Worker validates requests, stores submissions in Cloudflare D1, limits abuse, and can notify the configured inbox through Resend. Customer details are not copied into the public repository. Run [Deploy TradingLab03 Intake API](https://github.com/maazxhasan-hue/Tradinglab03-/actions/workflows/deploy-intake-api.yml) only after following [worker/README.md](worker/README.md). Without the Cloudflare and owner-key secrets, the API cannot be deployed; without the optional Resend settings, enquiries are stored but email alerts are not sent.

## AI draft worker and website builder
- **AI worker:** [Run manually in GitHub Actions](https://github.com/maazxhasan-hue/Tradinglab03-/actions/workflows/agent-worker.yml). Add repository secret `OPENAI_API_KEY` first. It generates drafts only and uploads an artifact.
- **Website draft builder:** [Run manually in GitHub Actions](https://github.com/maazxhasan-hue/Tradinglab03-/actions/workflows/website-draft.yml). It builds a static site and quality report for download; it does not deploy to a client's domain.
- **Local website build:** `python -m company.website_pipeline --brief config/website_brief.example.json --output data/website_drafts/example`
- **Local AI task queue:** `python -m company.agent_runtime --task-type summarize_opportunity --title "Review listing" --context "Paste a public listing here"`, then `python -m company.agent_runtime --run-one` (requires `OPENAI_API_KEY`).
