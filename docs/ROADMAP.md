# Roadmap

## Local MVP
- [x] Approved course facts, content draft generation, claim screening
- [x] Grounded FAQ and human escalation for unknown questions
- [x] Revenue gate based on verified, non-refunded receipts
- [x] 14-role development team and release gate
- [x] Local idempotent job coordinator with guarded state transitions

## Next phases
1. Add source-attributed research and daily content briefs.
2. Add human approval UI, voice/video production QA, captions and SEO drafts.
3. Add trusted payment reconciliation and refund-aware ledger.
4. Add publishing adapters only for explicitly authorized accounts; default disabled.
5. Add verified analytics and human support handoff.

## Non-negotiable release gates
- Tests pass, security review passes, owner approval is explicit, rollback is ready.
- No marketing access to brokerage credentials or private trading infrastructure.
- No unapproved spending, purchases, price changes, refunds, or bulk outreach.
- No invented claims, testimonials, sales, or performance statistics.
- Shutdown blocks new work and external actions; never deletes user data or cloud infrastructure automatically.
