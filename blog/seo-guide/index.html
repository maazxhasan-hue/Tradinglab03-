Practical SEO notes

A technical SEO checklist for small-business websites

Search optimization starts with helping search engines understand your pages and helping visitors find useful answers. These foundations are worth checking before chasing advanced tactics.

1. Give every important page a useful title

Write a distinct, readable <title> that reflects the page topic and brand. Add a concise meta description that accurately previews the content; it can help searchers decide whether to visit, but it is not a ranking guarantee.

2. Use a clear heading structure

Use one descriptive main <h1> for the page's main topic, then use <h2> and <h3> headings to organize meaningful sections. Headings should describe the actual content, not just repeat keywords.

3. Set canonical URLs carefully

Use an absolute canonical URL for the preferred version of each page. Ensure it points to a real, indexable page and is consistent with internal links and the sitemap. Do not canonicalize distinct useful pages to the homepage.

4. Publish an XML sitemap

List the canonical, public URLs that you want search engines to discover in /sitemap.xml. Keep it updated as pages change and include only URLs that should be indexed.

5. Review robots.txt

A /robots.txt file can guide compliant crawlers and point to the sitemap. It is not a privacy or access-control system; protect private routes with real authentication and server-side authorization.

6. Add accurate structured data

Use JSON-LD that describes the real organization, website, page, or article. Keep it consistent with visible page content, validate its syntax, and never add fake reviews, prices, or business claims.

7. Link related pages together

Use descriptive links between your services, pricing, about page, and helpful articles. Ensure each important page can be reached through ordinary links, not only a search form or JavaScript interaction.

8. Check mobile usability and performance

Test narrow screens, readable text, keyboard navigation, image sizes, loading behavior, and working forms. Fix broken links and make the next action clear.

Remember: these are technical foundations, not a promise of ranking or traffic. Useful content, competition, site history, external signals, and many other factors influence search results.
