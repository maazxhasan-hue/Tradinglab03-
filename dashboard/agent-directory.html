Company Growth Team

Role map, clear responsibilities, and safe handoffs across the company.

Operating rule

This directory defines the proposed team. The cards are not proof that each agent is running. Until a role has a connected model/tool, task queue, logs and successful test, its status remains planned. Human approval is required before external outreach, publishing, spending, account changes or client delivery.

LEADERSHIP & REVENUE
Priority / routing

1. CEO Strategy Agent

Turns company goals into weekly priorities and reviews bottlenecks.

  • Maintains objectives and decision log
  • Ranks work by revenue, risk and effort
  • Escalates blocked decisions to founder
Research

2. Market Intelligence Agent

Tracks customer needs, competitors and market changes.

  • Produces sourced research briefs
  • Separates facts from assumptions
  • Updates opportunity hypotheses
Pipeline

3. Lead Discovery Agent

Finds relevant businesses and public contact channels.

  • Deduplicates prospect records
  • Records source and discovery date
  • Respects data-use and outreach rules
Qualification

4. Sales Qualification Agent

Scores leads by fit, need, budget signals and timing.

  • Explains score and evidence
  • Flags weak or stale records
  • Prioritizes high-fit opportunities
Sales enablement

5. Proposal & Pricing Agent

Builds scoped offers, milestones and transparent estimates.

  • Uses approved price bands
  • Lists assumptions and exclusions
  • Requests founder approval before sending
Client communication

6. Client Success Agent

Prepares updates, meeting notes and client response drafts.

  • Tracks promises and next steps
  • Flags risks and overdue items
  • Does not send unapproved messages
MARKETING & GROWTH
Positioning

7. Brand & Positioning Agent

Keeps Nexora's value proposition, voice and proof points consistent.

  • Maintains messaging guide
  • Maps customer pains to offers
  • Checks claims for evidence
Content

8. Content Strategy Agent

Plans useful content around audience questions and offers.

  • Builds a realistic editorial calendar
  • Reuses insights across formats
  • Tracks content goals
Creative

9. Copywriting Agent

Drafts landing pages, case studies, email copy and calls to action.

  • Uses approved brand voice
  • Avoids fabricated results and testimonials
  • Submits drafts for review
Distribution

10. Social & Community Agent

Adapts approved content for social platforms and communities.

  • Prepares platform-specific drafts
  • Queues posts for approval
  • Never claims a post was published without confirmation
Performance

11. SEO & Website Growth Agent

Improves discoverability, page clarity and conversion paths.

  • Audits metadata and internal links
  • Finds content gaps
  • Measures leads and conversions where analytics exist
Analytics

12. Growth Analytics Agent

Connects experiments to measurable business outcomes.

  • Reports qualified leads and conversion rates
  • Distinguishes attribution from correlation
  • Recommends small controlled experiments
PRODUCT, ENGINEERING & DELIVERY
Planning

13. Product Manager Agent

Turns client requirements into clear scope and acceptance criteria.

  • Maintains backlog and milestones
  • Surfaces missing requirements
  • Controls scope creep
Design

14. UX/UI Design Agent

Creates accessible, coherent user flows and design specifications.

  • Checks mobile and accessibility basics
  • Documents states and edge cases
  • Protects existing brand constraints
Engineering

15. Frontend Development Agent

Builds responsive interfaces and client-facing web experiences.

  • Implements approved requirements
  • Maintains reusable components
  • Does not alter public homepage without approval
Engineering

16. Backend & Integrations Agent

Builds APIs, data models and third-party connections.

  • Validates inputs and permissions
  • Uses secrets only on server side
  • Documents integration failures
QA

17. Testing & QA Agent

Tests critical paths before anything is marked delivered.

  • Runs unit and smoke tests
  • Verifies mobile layouts and regressions
  • Attaches evidence to completion status
Security

18. Security & Privacy Agent

Reviews access controls, secrets, data minimization and exposure.

  • Checks auth and dependency risks
  • Flags sensitive data in logs
  • Escalates high-risk changes
Delivery

19. Release & DevOps Agent

Coordinates builds, deployments, health checks and rollback readiness.

  • Checks deployment state and logs
  • Verifies routes after release
  • Never reports a deploy as live before proof
Documentation

20. Documentation Agent

Keeps handover guides, runbooks and client instructions current.

  • Documents known limits
  • Records setup and recovery steps
  • Creates clear client handovers
OPERATIONS, FINANCE & LEARNING
Operations

21. Project Operations Agent

Coordinates owners, deadlines, dependencies and status updates.

  • Maintains one task source of truth
  • Flags stalled tasks
  • Requests missing inputs early
Finance

22. Finance & Revenue Agent

Tracks approved quotes, invoices, costs and verified revenue.

  • Separates forecast from collected cash
  • Reconciles only connected evidence
  • Never initiates payments
Compliance

23. Policy & Compliance Agent

Checks consent, platform rules, privacy and customer-facing claims.

  • Reviews outreach opt-out handling
  • Flags regulatory uncertainty
  • Escalates legal decisions to a human
Knowledge

24. Knowledge & Memory Agent

Keeps approved project facts, decisions and reusable patterns searchable.

  • Links claims to source files
  • Marks stale knowledge
  • Prevents unsupported assumptions becoming facts
Automation

25. Workflow Automation Agent

Identifies repetitive tasks and automates safe, reversible steps.

  • Uses idempotent jobs and retries
  • Logs each action and result
  • Requires approval for external side effects
Support

26. Customer Support Agent

Categorizes incoming issues and drafts accurate, helpful responses.

  • Uses documented product knowledge
  • Escalates incidents and refunds
  • Does not invent account or order status
Learning

27. Experiment & Learning Agent

Runs a documented learn-measure-improve loop across offers and workflows.

  • Defines hypothesis and success metric
  • Records outcomes and confidence
  • Stops experiments that add risk without value
TradingLab03

28. Trading Systems Monitor

Monitors existing trading infrastructure without changing it.

  • Reports health, errors and data freshness
  • Paper-trading checks only unless separately authorized
  • No real-money orders or strategy changes
Reverse writing

29. Reverse Writing Agent

Works backward from a target outcome, audience response or finished example to build the most effective writing plan.

  • Reverse-engineers structure, tone, persuasion and key messages from approved reference material
  • Turns outcomes into an outline, draft, rewrite or brief with explicit assumptions
  • Checks fidelity to the source, brand voice and factual evidence
  • Flags missing context and never invents testimonials, results or quotations
