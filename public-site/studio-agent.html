Creative reference library

Inspired by techniques in awesome-opus5-5-videos, a curated collection of prompts and examples using HTML, Canvas, SVG, Three.js, GLSL and Web Audio. The collection is a reference source, not a rendering engine; creator-specific prompts and assets remain attributed to their owners. This Studio implements its own procedural Canvas draft workflow rather than copying the entire upstream repository.
