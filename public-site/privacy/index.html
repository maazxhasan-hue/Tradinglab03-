5. Google Analytics and cookies

The website includes consent-gated analytics code intended to use Google Analytics 4 (GA4) only after the visitor chooses “Allow analytics.” The analytics Measurement ID is supplied through server configuration; if it is missing or invalid, GA4 remains inactive. The consent control offers “Only necessary” and “Allow analytics,” and visitors can reopen “Cookie settings” to change their choice. Global Privacy Control and Do Not Track signals prevent optional analytics from loading in the current implementation.

If enabled after consent, Google Analytics may process online identifiers, device/browser information, page views, approximate location derived from network information, traffic source, and engagement information according to Google's configuration and policies. The form implementation should not send names, email addresses, project goals, or other enquiry fields as analytics event parameters. Review the GA4 property settings, retention controls, Google Signals and advertising settings before publication.

Analytics is optional. Choosing “Only necessary” keeps optional GA4 analytics disabled. Necessary storage may be used to remember the visitor's analytics choice and support basic site security or functionality.
